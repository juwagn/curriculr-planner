# Curriculr Planner

Standalone web tool for school principals to create an annual school schedule.

## Quick Start

```bash
pnpm install
pnpm dev          # http://localhost:5173
pnpm test         # watch mode
pnpm test:run     # single run
pnpm build        # production bundle in dist/
```
