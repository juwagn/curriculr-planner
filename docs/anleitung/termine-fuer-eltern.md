# Termine für Eltern markieren

Sie brauchen:

- Zugriff auf den Planer und Ihren Schul-Terminplan
- Eine Anmeldung mit IServ (nur zum Veröffentlichen)
- Mindestens einen Termin, den Eltern sehen sollen

## Schritte

1. Klicken Sie in der Wochentabelle auf den Termin. Der Termin-Dialog öffnet sich.
2. Suchen Sie im Dialog den Abschnitt **Gruppen**.
3. Setzen Sie das Häkchen bei **Eltern**.
4. Klicken Sie auf **Speichern**.
5. Klicken Sie unten in der Statusleiste auf **Veröffentlichen**.
6. Klicken Sie auf **Jetzt veröffentlichen →**.

## Was Eltern sehen

- Die Eltern-Ansichten auf der Schul-Website zeigen nur Termine mit der Gruppe „Eltern“.
- Termine ohne diese Gruppe erscheinen dort nicht.
- Die **Kategorie** eines Termins bestimmt nur die Farbe. Sie entscheidet nicht, wer den Termin sieht.

## So prüfen Sie, ob es funktioniert

1. Öffnen Sie den Termin erneut. Bei **Gruppen** ist **Eltern** angehakt.
2. Öffnen Sie die Eltern-Ansicht auf der Schul-Website.
3. Der Termin steht dort in der richtigen Woche.

## Häufige Probleme

- **Der Termin fehlt auf der Website.** Prüfen Sie, ob Sie nach dem Speichern auch veröffentlicht haben.
- **Der Termin fehlt trotz Veröffentlichung.** Prüfen Sie, ob die Sichtbarkeit auf **Öffentlich** steht.
- **Die Schaltfläche heißt „Mit IServ anmelden“.** Melden Sie sich zuerst an. Danach erscheint **Veröffentlichen**.
- **Sie brauchen eine eigene Gruppe.** Tippen Sie bei **Gruppen** in das Feld **Eigene Gruppe (Enter)**.
