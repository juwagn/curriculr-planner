# Design: v1.2 "Komfort" — Vorlagen + Excel-Import + Schuljahr-Grid + Undo/Redo

**Date:** 2026-05-29
**Status:** Approved (brainstorming)
**Roadmap:** v1.2 in [2026-05-26-curriculr-planner-design.md](2026-05-26-curriculr-planner-design.md) (lines 633–658)
**Scope:** Next PR. Four features bundled. Ship as one PR with separate commits per
feature; the Undo/Redo and Vorlagen seams are splittable into a follow-up PR if the
diff grows too large (same approach as the v1.1 conflict/resize/ICS PR).

## Summary

Adds four comfort capabilities to the annual-plan editor:

1. **Termin-Vorlagen** — configurable templates in a left sidebar; drag (or
   click-to-place) onto a day creates a prefilled event.
2. **Excel-Import** — read a Konverter `.xlsx` into a `PlannerDocument` (inverse
   of the existing Excel export).
3. **Schuljahr-Grid** — a third view: a months × days 1–31 matrix, like the
   sibling WordPress plugin's year view.
4. **Undo/Redo** — snapshot-based history stack for content edits.

**Key finding:** No new dependencies. `@dnd-kit/core` (drag), `xlsx` (Excel),
and `@fullcalendar/multimonth` are already installed.

## Decisions (from brainstorming)

| Topic | Decision |
|---|---|
| Undo/Redo architecture | Snapshot-based (full doc copies, cap 50). Simpler + robust vs command/inverse-ops. Doc is small JSON. |
| Undo/Redo scope | Tracks content edits only: event create/edit/delete, move, resize, annotation set/delete. EXCLUDES schoolyear/category/group/template (Settings-level) edits. |
| Vorlagen interaction | Drag (dnd-kit) **plus** click-to-place fallback (touch/keyboard/a11y). |
| Vorlagen after-drop | Event created from template, Edit-Modal opens prefilled for adjust-or-save. |
| Schuljahr-Grid layout | Matrix (months × days 1–31), like WP-Plugin year view. NOT FullCalendar multimonth. |
| Vorlagen storage | `PlannerDocument.templates: EventTemplate[]` (persisted); managed in a Settings "Vorlagen" tab. |
| Schema version | Bump `2 → 3`; migrate adds `templates: []`. |
| Excel-import entry points | Welcome (new plan) + Settings (append), mirroring shipped ICS-import dual entry. |
| Excel category mapping | Reuse the ics-import keyword-match chain + fallback (`sondertag`). |
| Excel missing schoolyear dates | Open Wizard prefilled with parsed values. |
| New deps | None. |

### Data model

```ts
interface EventTemplate {
  id: UUID;
  name: string;            // sidebar label
  categoryId: UUID;
  defaultTitle?: string;   // prefills event title; falls back to name
  allDay: boolean;
  startTime?: ISOTime;     // required when !allDay
  endTime?: ISOTime;
  defaultGroups: string[];
}

// PlannerDocument
version: 3;
templates: EventTemplate[];   // default []
```

`EventTemplateSchema` mirrors `PlanEventSchema`'s time/all-day refinement
(times required when not all-day).

### Undo/Redo flow

- `stores/history.ts`: `{ past: PlannerDocument[]; future: PlannerDocument[] }`,
  both capped at 50 (drop oldest past on overflow).
- `planner.ts` content mutators call `pushHistory(currentDoc)` BEFORE applying the
  edit; this clears `future`.
- Annotation typing coalesces: one snapshot per week-edit session (e.g. snapshot on
  first keystroke for a given schoolweek, not every character).
- `undo()`: pop `past` → push current onto `future` → `setDoc(popped)` → debounced save.
- `redo()`: symmetric.
- Settings-level mutators (`updateSchoolyear`, `updateCategories`, `updateGroups`,
  template CRUD) do NOT call `pushHistory`.
- History store resets on `setDoc` from load/switch/import (fresh doc = empty stack).

### Schuljahr-Grid (Matrix)

- Rows: each month from `firstSchoolDay` month through `lastSchoolDay` month.
- Columns: day-of-month 1–31; cells for non-existent days (e.g. Feb 30/31) rendered
  greyed/empty.
- Cell fill: category color via `colors.ts` (multi-event day shows a stacked/striped
  indicator). Ferien days hatched via existing `schoolweeks` holiday detection.
- Click a cell → open Edit-Modal for that date (create) or first event there (edit).
- Cells are dnd-kit droppables so event-move and template-drop work in this view too.
- `ui.ts` `viewMode: 'table' | 'calendar' | 'year'` (persisted); header toggle gains
  the third option.

### Excel-Import

- `parseKonverterXlsx(buffer)` (pure): reads Ferien + Terminplan sheets per the
  Konverter schema that `excel-export.ts` already produces (inverse direction).
- Returns `{ schoolyear?: Partial<Schoolyear>; events: PlanEvent[] }`.
- Category resolution reuses the ics-import keyword-match chain + `sondertag` fallback.
- Welcome entry → new plan (open Wizard prefilled if schoolyear dates incomplete).
- Settings entry → append into current plan.
- Where practical, reuse `IcsImportDialog`'s summary/target/shift shell as a shared
  import dialog.

## Build order (splittable seams)

1. **Schema + migration v2→v3** (`templates`, EventTemplate) — foundation.
2. **Excel-import** (`excel-import.ts` + tests → Welcome + Settings wiring) — independent.
3. **Schuljahr-Grid** (`YearGrid.tsx` + viewMode 'year' + header toggle) — independent.
4. **Undo/Redo** (`history.ts` + planner hooks + `useUndoRedo` + toolbar) — splittable.
5. **Termin-Vorlagen** (`TemplatesSidebar.tsx` + planner template CRUD + Settings tab) — splittable.

Steps 4–5 are the seam to peel into a follow-up PR if the diff grows too large.

## Success criteria (from roadmap)

- [ ] Template drag shows visual drop-zone feedback.
- [ ] Excel-import of a ~50-event Konverter file completes < 3 s.
- [ ] Schuljahr-Grid scrolls fluently at 200+ events, no layout shift.
- [ ] Undo after a drag-move restores the exact original position.
- [ ] A Settings edit (e.g. category rename) does NOT appear in the undo stack.

## Out of scope (YAGNI)

- Cloud-Sync (v1.3), RRULE/recurrence (v1.4).
- Template categories/folders — flat list only in v1.2.
- Excel-export changes — export already exists; this PR is import only.
- Multi-day template defaults — templates seed single-day events; resize after.
- Undo for Settings-level edits (explicitly excluded per decision).
